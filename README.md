# Devotly — Daily Devotionals, Prayer & Scripture

Devotly is a beautifully crafted companion for everyday faith — devotionals, sermons, prayer timer, fasting tracker, reading plans, family sharing and more.

## Features
- Daily devotionals & sermons crafted for personal, family, encouraging and deep study
- Word of the Day & Scripture of the Day with notifications and in-app preview
- Prayer timer & fasting tracker with local notifications
- Bible in a Year reading plan and scripture search
- Notes, highlights & family sharing
- Installable PWA — add to Home Screen for offline access
- Subtle motion & polished interactions throughout

## Tech
- Vite + React + TypeScript + Tailwind + shadcn/ui
- Supabase (Auth, Postgres, Edge Functions)
- Framer Motion for motion graphics
